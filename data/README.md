# Данные соревнования
Положите рядом с ноутбуком или сюда три файла: `train.csv`, `test_feat.csv`, `submission_example.csv`.
Ожидаемый размер: train — 5 557 строк, test — 1 390 строк. Цель: `дефолт`, ключ: `ID`.
Исходные данные и готовые предсказания не опубликованы. Получите их в своём доступе к соревнованию Kaggle «Проект МО УЦП2026» и соблюдайте его условия.
При другом расположении задайте `DATA_DIR` в ноутбуке. В бизнес-дополнении отдельно доступны `BM_TRAIN_PATH` и `BM_DATA_DIR`.
